# 机械动力：滑轨
#### 一个为航空学添加简单的 [导轨](doc/zh_cn/导轨.md)、[滑块](doc/zh_cn/滑块.md) 和 [传送带固定夹](doc/zh_cn/传送带固定夹.md) 的试做模组

---

## 以下信息截至当前最新版本, 具体情况请在游戏中验证

### 简单描述:
| 方块               | 描述                                                             |
|--------------------|------------------------------------------------------------------|
| `guide_rail`       | 为`slide_block`提供稳定运动环境                                  |
| `slide_block`      | 借助 Sable 的 tag 实现低摩擦并在`guide_rail`提供的稳定环境中运动 |
| `belt_fixing_clip` | 使用约束器将自身所属子维度约束到传送带表面                       |

### 使用方法:
| 方块               | 描述                                                                     |
|--------------------|--------------------------------------------------------------------------|
| `guide_rail`       | 直接放置即可                                                             |
| `slide_block`      | 直接放置即可, 若需要移动到`guide_rail`中需要装配为子维度, 然后移动到其中 |
| `belt_fixing_clip` | 手持物品右键传送带表面, 即可在表面生成一个携带该方块的子维度并建立约束   |


### 当前缺点:
| 方块               | 描述                                                                           |
|--------------------|--------------------------------------------------------------------------------|
| `guide_rail`       | 未实现组合方块, 也就是导轨与滑块组合在一起, 并可以直接装配滑块上结构的组合方块 |
| `slide_block`      | 同`guide_rail`                                                                 |
| `belt_fixing_clip` | 目前仅实现水平正表面的可能正确的功能实现                                       |


### 依赖模组:
| 模组名 | 用途                                     |
|--------|------------------------------------------|
| Create | `belt_fixing_clip`依赖目标方块`belt`来源 |
| Sable  | 物理模拟根本, 不必多说                   |
